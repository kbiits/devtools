Python → JSON

Convert Python literals (dicts, lists, tuples, etc.) to JSON

Supported syntax:

  • Dicts: {'key': value}
  • Lists: [1, 2, 3]
  • Tuples: (1, 2, 3) or (1,)
  • Strings: 'single' or "double" with escapes
  • Numbers: 42, 3.14, 1e10
  • Booleans/Null: True, False, None
  • Trailing commas allowed

Note: Sets, function calls, and arbitrary expressions are not supported.
